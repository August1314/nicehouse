"好房子"三维可视化系统项目汇报内容文档
1. 项目概述
本项目是一个基于Unity引擎开发的"好房子"三维可视化系统，围绕"安全、舒适、绿色、智慧"四大核心需求，体现了"以人为中心"的设计理念。系统集成了多种智能家居功能模块，实现了环境控制、健康监测、安全防护等核心功能，并提供了丰富的数据可视化手段。

2. 系统架构与技术实现
2.1 核心架构
数据层：统一的数据管理模块，包括环境数据、健康数据、安全数据、能耗数据等
控制层：各类功能控制器，如环境控制器、健康监测控制器、智能监护控制器等
展示层：UI面板、3D可视化组件、控制中枢面板等
交互层：第一人称控制器、射线交互系统、设备交互组件等
2.2 技术特点
使用Unity引擎和C#编程语言
采用模块化设计，便于扩展和维护
实现了完整的数据驱动架构
支持第一人称和第三人称视角切换
集成了丰富的3D交互和可视化效果
3. 功能模块详解
3.1 环境智控模块（舒适+智慧）
功能亮点：

实时监测PM2.5、PM10、温度、湿度等环境指标
自动联动控制空调、新风系统、空气净化器等设备
提供手动控制界面和自动/手动模式切换
支持温度调节和设备状态可视化
技术实现：

EnvironmentDataStore：环境数据存储和管理
EnvironmentController：环境控制逻辑和自动联动
EnvironmentControlPanel：UI控制面板
3.2 智能监护模块（安全+智慧）
功能亮点：

实时监测数字人行为状态（站立、行走、久坐、久浴、睡觉、跌倒、坠床等）
异常行为检测和自动告警
告警响应系统（UI提示、音效、灯光闪烁）
支持手动状态切换用于演示
技术实现：

PersonStateController：数字人状态管理
PersonStateManager：多数字人状态管理
MonitoringController：监护逻辑和异常检测
MonitoringPanel：监护UI面板
3.3 健康监测模块（安全+智慧）
功能亮点：

实时监测心率、呼吸率、体动强度、睡眠阶段等生命体征
健康异常检测和告警
健康数据可视化和历史趋势展示
与告警系统集成
技术实现：

HealthDataStore：健康数据存储和模拟
HealthMonitoringController：健康监测逻辑
HealthMonitoringPanel：健康监测UI面板
3.4 安全防护模块（安全+智慧）
功能亮点：

烟雾和燃气浓度监测
异常情况自动告警和联动响应
声光报警和窗户自动开启
全屋监控和人物跟踪（可选）
技术实现：

SafetyDataStore：安全数据存储和管理
SafetyDataThresholds：安全阈值配置
告警响应系统集成
3.5 能耗智控模块（舒适+绿色+智慧）
功能亮点：

实时监测各设备能耗和累计用电量
能耗数据可视化展示
总体能耗统计和分析
与设备控制系统集成
技术实现：

EnergyManager：能耗管理和计算
EnergyConsumptionPanel：能耗展示面板
3.6 一键呼叫模块（安全）
功能亮点：

紧急情况一键求助功能
告警信息推送和现场警示
与告警系统无缝集成
技术实现：

EmergencyButton：紧急按钮组件
EmergencyButtonVisual：按钮视觉反馈

## 项目总览
- 目标：基于 Unity 搭建“好房子”三维可视化系统，围绕安全、舒适、绿色、智慧，突出“以人为中心”。
- 场景：主房屋模型 + 数字人 + 设备/传感器，支持主菜单/演示模式切换。
- 交互：第一人称漫游 + 射线交互，墙体控制中枢面板作为统一入口。

## 架构与场景组织
- 场景结构：`MainMenu`（模式选择）、`HouseScene`（主三维场景：客厅/厨房/书房/走廊/卧室/卫生间、数字人、传感器与设备）。
- 模块划分：环境智控、智能监护、健康监测、系统分层可视化、灯光交互、控制中枢面板（统一入口），外加数据底座（EnvironmentDataStore/HealthDataStore/AlarmManager/ActivityTracker 等）。
- 技术要点：摄像机控制、UI交互、设备控制器、时间轴/动画、Shader 图层可视化。

## 功能模块对标作业要求
- 功能可视化（≥2项，20分）
  - 环境智控（舒适+智慧）：实时监测 PM2.5/PM10/温湿度；阈值触发新风/空调/净化器联动；自动/手动模式；设备动画与告警提示。
  - 智能监护（安全+智慧）：监测数字人久坐/久浴/跌倒/坠床；自动告警（UI+音效+灯光闪烁）；告警列表与处理；状态模拟便于演示。
  - 健康监测（安全+智慧）：心率/呼吸/体动/睡眠实时显示与历史趋势；阈值异常告警；与 AlarmManager 打通。
  - 灯光交互（舒适+能耗关联）：第一人称准星射线开关灯，支持能耗计入 EnergyManager。
- 系统分层查看（≥2项，20分）
  - 剖面/楼层隐藏与高度滑块。
  - 环境图层：温度渐变、湿度双色区间、PM2.5 分级闪烁。
  - 活动热力图：房间访问频次/停留时长（支持累计/回放模式，时间轴控制）。
  - 告警叠加：烟雾/跌倒等房间脉冲高亮。
- 进阶要求对齐（30分）
  - 功能全量呈现：环境、监护、健康、（可扩展能耗、一键呼叫、安全防护）。
  - 全量分层：剖面+温度+湿度+PM2.5+热力图，带时间轴回放。
  - 数字人与“以人为中心”：监护/健康基于数字人状态，联动告警与设备控制；控制中枢面板降低操作门槛，支持第一人称快速访问。

## 各模块特色与亮点
- 环境智控
  - 场景化联动：雾霾/高温/低温/湿度异常触发设备；PM 传感器材质闪烁提示。
  - 设备全链路：空调/新风/净化器/风扇控制 + 动画；自动节能（能耗超阈值关闭空调）。
  - UI 交互：温控面板点击弹出数据面板；自动/手动模式切换。
- 分层数据可视化
  - 剖面浏览 + 图层选择器 + 图例/阈值锁定。
  - 温湿度/PM2.5 渐变材质；告警脉冲贴花；热力图时间回放。
  - 对比模式：主副图层叠加（如温度+活动热力）。
- 智能监护
  - 状态判定：久坐/久浴超时、跌倒、坠床即时告警。
  - 联动响应：UI 弹窗 + 音效 + 房间灯光闪烁，告警处理闭环。
  - 演示友好：状态模拟器按钮/脚本，便于课堂演示。
- 健康监测
  - 生命体征多指标：心率、呼吸、体动、睡眠阶段。
  - 阈值与持续时间双重判断，避免误报；告警接入 AlarmManager。
  - 历史趋势图表（可用 UI 图表组件）。
- 灯光交互
  - 第一人称准星射线点击；悬停高亮提示“开灯/关灯”。
  - 能耗计入 EnergyManager，体现绿色/节能。
- 控制中枢面板
  - 墙体嵌入式 Sci-Fi 入口，集中呈现各功能状态摘要与一键唤起。
  - 与 FPRaycastInteractor 联动，降低学习成本；可扩展“网页式”内嵌子页面。
- 演示动线
  - 门口 → 客厅（环境/温度层）→ 厨房（PM/湿度层）→ 书房（活动热力/健康监测）→ 走廊（时间轴/剖切）→ 卫生间（监护告警）→ 卧室（睡眠+环境）。

## “以人为中心”体现
- 数字人驱动：监护/健康以数字人状态和生命体征为核心触发。
- 主动适配：环境超标自动联动设备；能耗超阈节能；告警自动推送。
- 低负荷交互：第一人称射线 + 控制中枢面板，减少操作路径；告警可一键处理。
- 可视化直观：分层视图、热力图、图例阈值锁定，所见即所得。

## 评分点对应关系速览
- 三维模型：完整房屋 + 设备/传感器 + 数字人（可导入/自建）。
- 功能可视化：环境智控、智能监护、健康监测、灯光交互（满足≥2项，且交互强）。
- 分层查看：剖面 + 温度 + 湿度 + PM2.5 + 活动热力（满足≥2项，支持动态）。
- 进阶：全量功能/分层 + 数字人融合 + 新特色（控制中枢、时间轴回放、能耗联动）。

## 技术与实现亮点
- 数据底座：EnvironmentDataStore / HealthDataStore / ActivityTracker / AlarmManager 统一接口；时间轴回放缓存。
- 设备控制器：空调/净化器/风扇/灯光控制，含动画与能耗写入。
- Shader/材质：剖切 Clip Plane、渐变热力、告警脉冲、Sci-Fi 面板发光。
- 交互体系：FPRaycastInteractor + IRaycastInteractable，统一 Hover/Click 回调；Crosshair UI 提示。
- UI 体系：LayerPanel、LegendPanel、Timeline、MonitoringPanel、HealthPanel、ControlHubPanel 等可复用组件。
